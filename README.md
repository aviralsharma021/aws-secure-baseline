# aws-secure-baseline
A production-style AWS baseline demonstrating secure-by-default infrastructure design — built, hardened, and scanned end-to-end as a hands-on complement to AWS Certified Security – Specialty prep:

A hardened, security-first AWS infrastructure baseline built with Terraform — VPC segmentation, least-privilege IAM, KMS encryption, and centralized logging, with automated IaC security scanning (checkov/tfsec) and secret detection gated into CI/CD via GitHub Actions.
